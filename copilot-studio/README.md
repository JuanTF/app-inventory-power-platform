# Copilot Studio — Asistente de inventarios

El proyecto incluye un asistente conversacional que permite consultar información de productos (por ejemplo, cantidades, precios y ubicaciones). La lógica de consulta del inventario mediante Power Automate se encuentra en [`consulta-inventario-agente.json`](../power-automate/definitions/consulta-inventario-agente.json).

![Respuesta del asistente](../docs/images/08-asistente-ia.png)

**Alcance del repositorio:** el archivo original no incluía la exportación del agente de Copilot Studio, por lo que aquí se conserva su evidencia visual y el flujo relacionado, no un bot importable.
